# P2.3 UI 到输出记录

执行日期：2026-10-24。

## 实现

- `ui/camera_whiteboard/publisher.py`：把 `render(canvas, 1280, 960)` 的结果按 33 ms 周期写进
  `.run/frames.bin`（协议见 frame-protocol.md）。
- 画布新增 `revision` 与 `active_stroke`：内容没变时复用上一帧渲染结果，但**仍然每帧写入**，
  否则媒体源的 2 秒陈旧判定会把它当成故障。
- `app.py` 接 QTimer 定时发布；托盘增加"输出深色底"开关（透明底在部分客户端里会显示成黑色）。

## 端到端验证（本机，不经人工操作）

1. 离屏启动应用，画一条白色波浪线 + 两个青色十字。
2. 另一进程 `read_vcam.py` 读摄像头输出并存 PNG。

结果：

| 项 | 值 |
|---|---|
| 发布帧数（400 ms） | 8 |
| 文件头 | magic `31425743`、ver 1、1280×960、stride 5120、seq 偶数、state 1 |
| 摄像头读到的画面 | 波浪线与十字均出现（`.run/frame_ui.png`） |
| 读取侧判定 | 通过（帧率 41.9 fps、时间戳单调） |

说明：该路径下"不同画面数"只有 2，因为画布静止后发布的内容相同——符合预期。

## 结构变更（2026-10-24 第二轮反馈）

用户反馈三点后重构：

1. **拖动一次后无法再拖** —— 视口窗口与全屏透明悬浮层都在置顶带内，移动后悬浮层压在上面，
   标题栏被吃掉，只剩画布区域能落笔。
2. **全屏都能画** —— 悬浮层覆盖整个虚拟桌面，输入不进桌面。
3. **输出是透明底** —— 会议软件里显示为黑。

改法：**取消全屏悬浮层，白板改为一块白底窗口**（`viewport.py` 同时承担画布与窗口职责）。

| 项 | 结果 |
|---|---|
| 绘制范围 | 仅窗口内（框外鼠标落到桌面，正常操作其他软件） |
| 纸面 | 白色不透明，标题栏深色区分 |
| 输出底色 | 白（`background=(255,255,255,255)`），实测空白处像素 `255,255,255,255` |
| 拖动 / 缩放 / 关闭 | 都在窗口自身，不再有层级争抢；缩放锁 4:3 |
| 穿透（Ctrl+Alt+F8） | 语义改为"让白板窗口不挡手" |

`overlay.py` 保留但**不再接入**，留给将来的"桌面标注"模式；仍在文件头记录了
"分层窗口 alpha=0 不参与命中测试"这个坑。

测试：viewport 12 例（区域同步、拖动、4:3 缩放、纸面为白、标题栏为深色、绘制坐标、移动窗口后落笔、
橡皮、关闭信号、穿透标志），全库 54 例通过。


## 白板面板版式（2026-10-26）

需求：合成画面里白板要有**可见边界**，并且能指定它出现在对方屏幕的位置。

实现 `ui/camera_whiteboard/layout.py`：

- 输出帧固定 1280x960，白板是一块白色面板 + 3px 边框 + 投影，浮在摄像头画面上。
- **13 个锚点**：九宫格 9 个（左上/上中/右上/左中/居中/右中/左下/下中/右下）
  + 三分法 4 个交点（三分左上/右上/左下/右下）。三分法锚点让面板**中心**对准交点。
- **3 档大小**：小 30% / 中 42% / 大 58%（占输出宽度），面板恒为 4:3。
- 贴边留 3% 余量，并夹在画面内不会越界。
- 托盘 → 画布位置 / 画布大小 可实时切换。

注意：只有"叠加摄像头画面"开启时版式才生效；纯白板模式下输出就是整幅白板。
